# Polarizados Walter

Landing estática hecha con React, Vite y Tailwind CSS.

## Uso

```bash
npm install
npm run dev
```

Para generar el sitio de producción: `npm run build`. Vercel detecta Vite automáticamente; usá `npm run build` como Build Command y `dist` como Output Directory si te lo solicita.

## Personalización pendiente

- Reemplazá la imagen de placeholder del hero en `src/components/Hero.jsx` por fotos propias del local o trabajos terminados.
- Confirmá días/horarios y actualizalos en `Location.jsx`, `Footer.jsx` y el schema de `App.jsx`.
- Validá los textos de reseñas contra el perfil oficial antes de publicarlos.
